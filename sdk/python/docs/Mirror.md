# Mirror

Horizontal mirroring of the features. - `none`: Never mirrored. - `kingFile`: Mirrored when the perspective's own king is on files e–h.

## Enum

* `NONE` (value: `'none'`)

* `KINGFILE` (value: `'kingFile'`)
